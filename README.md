# Кол-во символов в редакторе

Прототип редактора DTF со счётчиком символов и переключением вариантов:

- С лимитом: 100 символов для тестирования, публикация блокируется при превышении.
- Без лимита: «Символов: …», без ограничений.

На мобильных экранах счётчик расположен в плавающей плашке справа внизу.

Запуск: `python3 -m http.server 8765`, затем открыть http://localhost:8765/.

GitHub Pages публикуется автоматически при обновлении ветки main.
Исходный MHTML, дизайн-система и снимки сохранены в репозитории; на Pages публикуются только файлы прототипа.
